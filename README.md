# new-game-project
A ping pong based simulator

Hi! This is a basic game that went from being an attempt at making a pong game to a... pong simulator of sorts. there was a glitch that made the ball push the padel. therefore i gave the padel up and down controls as well. afterward, i found that there were a bunch of jank interactions that could be done with the ball. i fixed the gamebreaking ones, added another padel and color coded hit counters for each padel, and a bunch of balls. only the yellow ball gives points, although all the balls make a sound when hit. all of the balls make the same sound.

now for some more specific details. i almost exclusively used Godot Engine to make my game. i took a copyright free image for the background and downloaded a free sound effect for the ball impact sound effect. i used the language that is used in Godot Engine. it was made from me wanting to make a simple ball and padel game to avoid deadline constraints. most of the problems were fixed with help from the event organisers. a few problems in particular  were repurposed into features. one was how the ball moves the padel, which had the game go from keeping the ball away from the bottom to bouncing the ball as you wish, with four directional control over the paddle instead of two. the reason for a golden ball is because i completed all the code for a single ball then duplicated it four times. the counter only worked for the fifth ball. i coloured it instead of trying to fix the code, and from a gameplay standpoint it makes points require more input to get.

to run the project, download it on godot engine and click the run button. this is a two player game. to control the black padel, use the wasd keys. to control the white padel, use the arrow keys. the padel is fast and the ball is faster, so keep that in mind.
